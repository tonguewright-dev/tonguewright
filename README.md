# tonguewright

`tonguewright` is an offline-first web application for creating constructed languages. It incorporates the best of modern linguistics theory in a way that is easy to use for beginners, but satisfying for those who know more.

As of the writing of this document, `tonguewright` does not exist in any meaningful form beyond this document, but hopefully it will soon. I (the developer) have a regular job outside of this, and am also currently studying for a master's degree in linguistics, so time is tight. But we'll see what I can manage on the odd evening that I am not working on term papers.

## Goals

- Absolutely no Generative AI at any point in this project. (This does not extend to any of the external libraries that may be used. Unfortunately a lot of code these days is written using AI, and that code can't be avoided, but I can still refuse to use AI myself)
- Easy to use for those who are unfamiliar with linguistics, but still satisfying for those who are familiar.
- Simple but thorough explanations of the parts of linguistics theory that are incorporated.
- Offline-first. All data is stored on the user's computer.
- Opt-in cloud storage. Users will be responsible for hosting their own instance of the cloud storage server. This process will be made as simple as possible by providing all the necessary code as well as instructions. This is primarily to save costs. I intend to host the application on Cloudflare, and would like to stay within the bounds of the free tier as much as possible.

## Roadmap

> Legend: ✅ = complete, 🛠️ = in progress, ⏱️ = future

- ⏱️ Phonology
  - ⏱️ User can create a phonological inventory by selecting phonemes from an IPA chart.
    - ⏱️ IPA chart can be a regular table (better accessibility)
    - ⏱️ IPA chart can be a fully navigable canvas (better page layout)
    - ⏱️ Phonological inventory can be selected from a preset.
  - ⏱️ User can select syllable structure constraints
    - ⏱️ Syllable constraints can distinguish **C**onsonants and **V**owels only (basic).
    - ⏱️ Syllable constraints can distinguish **O**bstruents, **N**asals, **L**iquids, **G**lides, and **V**owels (advanced).
    - ⏱️ Additional phonotactic constraints can be applied (such as banning `tl` clusters)
    - ⏱️ Constraints can be selected from a preset.
  - ⏱️ User can create phonological rules
    - ⏱️ Phonological rules can be formulated using the classical generativist model (i.e. text-based find/replace rules)
      - ⏱️ Phonological rules can use either individual segments (e.g. `p`, `t`, `k`) or abstract features (e.g. `[+voice]`, `[-continuant]`)
    - ⏱️ Phonological rules can be formulated using feature-tree geometry (advanced).
    - ⏱️ Phonological rules can be selected from preset examples with explanations.
- ⏱️ Lexicon
  - ⏱️ User can add words generated by the phonology.
  - ⏱️ User can manually type words, which are verified against the phonology.
  - ⏱️ User can specify meaning, semantic domain, part of speech, and relationships to other words.
  - ⏱️ User can populate the lexicon with a wordlist.
- ⏱️ Grammar
  - ⏱️ User can create derivational patterns (e.g. `verb + -er => actor noun`).
  - ⏱️ User can create inflectional patterns (e.g. declensions, conjugations).
  - ⏱️ User can create phrase structure rules.
- ⏱️ Texts
  - ⏱️ User can write texts/stories in their language as example data.
  - ⏱️ User can write examples/grammar sketches for a publishable document (see Download/Upload)
- ⏱️ Download/Upload
  - ⏱️ User can download all their language data.
  - ⏱️ User can upload previously downloaded data without issue.
  - ⏱️ User can download a formatted document of their language that is easily sharable.
- ⏱️ Cloud Storage
  - ⏱️ User can opt-in to cloud storage (self-hosted)
    - ⏱️ Documentation is provided to help in the process of setting up a cloud storage instance.
  - ⏱️ User can use cloud storage to synchronize their data across devices.

## Technical Details

The web application will be built using [Svelte/SvelteKit](svelte.dev) and will be hosted on [Cloudflare](https://www.cloudflare.com/)
